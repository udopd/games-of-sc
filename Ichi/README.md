# Mochi and the Boxes — SUPER CUBE Games Platform

Рефакторинг `Mochi_SUPER_CUBE_Games_Platform_v1.2.zip`.
Сохранены все 25 уровней, пиксельная графика, адаптивный интерфейс,
облачный прогресс, розовая кнопка избранного и материалы каталога.

## Запуск

Загрузите ZIP целиком в SUPER CUBE. `index.html` находится в корне,
`runtime.txt` содержит `browser`. Сборка не нужна. SDK внедряется платформой
автоматически, его копию в проект подключать не нужно.

Для самостоятельной игры откройте `index.html` или запустите в корне проекта
`python -m http.server 8000` и откройте `http://localhost:8000`.
Без платформы доступен гостевой режим с локальным прогрессом, если браузер
разрешает localStorage. HTTP-сервер нужен только для локальной разработки.

## Структура

```text
index.html                   Разметка, метаданные, относительные ссылки CSS/JS
runtime.txt                  browser
assets/
  css/styles.css             Статические стили, адаптивность и анимации
  js/
    namespace.js             Единственное пространство имён window.Mochi
    level-data.js            Загрузка карт из source/*.levels.json
    bootstrap.js             Запуск игры после загрузки карт
    levels.js                Названия уровней и игровая схема
    engine.js                Разбор карты, ход, толчок, отмена, победа
    progress.js              Формат прогресса, объединение, локальное хранение
    platform.js              SDK, загрузка/очередь записи, события, избранное
    audio.js                 Синтез звуков Web Audio
    sprites.js               Палитра и пиксельная графика
    renderer.js              Canvas, анимации, частицы, размер поля
    ui.js                    Меню, счётчики, диалоги, бургер, уведомления
    input.js                 Клавиатура, свайпы, тапы, экранные кнопки
    app.js                   Инициализация и взаимодействие модулей
media/                       Исходные описания, теги, обложка, скриншоты
source/                      chapter1.levels.json, chapter2.levels.json и генераторы уровней
tests/engine.cjs              Проверки карт, решений, отмены и прогресса
tests/browser.cjs             Браузерные проверки с тестовым SDK
docs/browser-results.json    Результаты выполненного браузерного прогона
VALIDATION.md                Проверки и ограничения
CHANGED_FILES.md             Полный список изменений относительно v1.2
```

Каждый модуль заключён в собственную функцию и предоставляет явный интерфейс
через `window.Mochi`. Движок не использует DOM, SDK, хранилище или таймеры.
Только `platform.js` обращается к `window.SuperCubePlatform`; обновление UI
передаётся ему через callbacks. `app.js` связывает компоненты и управляет сессией.
При запуске игра и редактор загружают карты из `source/chapter1.levels.json` и `source/chapter2.levels.json`. Файлы должны содержать по 25 уровней. Если браузер запрещает `fetch` при открытии через `file://`, используются встроенные копии `chapter1.generated.js` и `chapter2.generated.js`; для работы именно с исходными JSON запускайте локальный HTTP-сервер.

Загрузчики сначала читают JSON уровней, затем подключают игровые скрипты по порядку. Генератор главы 1 обновляет `source/chapter1.levels.json`, а генератор главы 2 — `source/chapter2.levels.json`.

## iframe и ресурсы

Игра проверена с `sandbox="allow-scripts"`, без `allow-same-origin`.
Пути относительные и работают при размещении во вложенном каталоге.
Игровой код не обращается к родительскому DOM, cookie или закрытым API.
Не требуется расширять sandbox. В `tests/browser.cjs` есть отдельный тестовый
host и имитация SDK с `postMessage`; игровая страница их не подключает.

В таком iframe localStorage обычно недоступен. Исключение перехватывается,
гостевой прогресс остаётся в памяти текущего экземпляра. После его закрытия
или перезагрузки он теряется. Для сохранения между сессиями на платформе
требуется авторизация и SDK.

## Сохранения и SDK

- Сохранены ключ `mochi-sokoban-v1` и схема
  `{version:1, completed, best, last, updatedAt}`. Индексы уровней — от нуля.
- После `getUser()` для авторизованного игрока вызывается `loadSave()`.
  Восстанавливаются завершённые плитки, счётчик, шкала и выбранный уровень.
- Поддержаны объект прогресса, JSON-строка и обёртки `save`/`data` из v1.2.
  Слияние объединяет завершённые уровни и выбирает минимальные рекорды ходов.
  Загрузка во время игры не переключает активный уровень.
- Неизвестный формат или ошибка чтения блокирует запись до успешной загрузки.
  Пустое облако не перезаписывается пустым состоянием при старте.
- Сохранение имеет очередь и повторные попытки; победа сохраняется сразу,
  выбор уровня — с небольшой задержкой. Вызовы SDK обёрнуты в Promise и
  try/catch, тайм-ауты не блокируют игру.
- Поддержаны поздняя инъекция SDK и авторизация после старта. Кнопка
  «Синхронизировать прогресс» повторно читает облако и объединяет прогресс.
- `track('level_start', {label:'level-N'})` вызывается при старте/рестарте,
  `track('level_complete', ...)` — после победы. До появления SDK события буферизуются.
- `favorite()` вызывается по нажатию розового сердца после проверки авторизации.
  Состояние кнопки меняется после подтверждённого ответа. Это переключение:
  исходный статус неизвестен, поскольку API не предоставляет отдельный getter.
- `share`, `rate`, `review` не вызываются: соответствующего интерфейса нет.

## Управление

Стрелки/WASD — ход; Z/Backspace — отмена; R — рестарт; Escape — меню.
На сенсорном экране доступны свайп и тап по соседней клетке.
В бургер-меню — экранные стрелки, отмена, рестарт, правила, звук, избранное,
синхронизация и переход к уровням. Страница не прокручивается; содержимое
длинного бургер-меню можно прокручивать внутри панели.

## Зависимости и проверки

У игры нет внешних runtime-зависимостей, CDN, сетевых шрифтов или build scripts.
Canvas 2D и Web Audio — браузерные API. Nunito указан как локальный шрифт
с системными fallback. Статические файлы каталога игрой не загружаются.
Генератор уровней использует только стандартную библиотеку Python 3.

`node tests/engine.cjs` проверяет правила без зависимостей.
Для браузерных тестов нужны Node.js, Playwright и Chromium. В отдельной копии
проекта выполните `npm install --no-save playwright`, затем
`npx playwright install chromium` и `node tests/browser.cjs`.
Переменная `BROWSER_EXECUTABLE` позволяет выбрать установленный Chrome/Chromium,
`TEST_OUTPUT` — папку результатов (по умолчанию `test-results/`).
Не добавляйте установленные пакеты и новые результаты тестов в публикуемый ZIP.

## Каталог, лицензии и атрибуция

`media/title.txt` содержит английское `Mochi and the Boxes`. Описания RU/EN,
теги RU/EN, JPEG-обложка 630×500 и оба скриншота сохранены побайтово.
Для публичных категорий используется `media/tags.en.txt`.
`runtime.txt` и оба файла `source/` также неизменны.

Исходный README указывает, что код игры, пиксельные иллюстрации и обложка
созданы в рамках этого проекта. В исходном ZIP нет отдельных сторонних
лицензий или файлов атрибуции; существующие материалы не удалены,
новая лицензия не назначена. Внешние медиа и лицензируемые шрифты не добавлялись.
Название SUPER CUBE относится к соответствующей платформе; её условия
использования продолжают действовать. Playwright нужен только для тестов
и не включён в runtime игры.
